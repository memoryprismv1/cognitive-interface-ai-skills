# Memory Prism — Optional Reference Card

**Purpose:** Give an assistant that does not already know Memory Prism enough grounding to understand the optional checklist and find the original sources.
**Boundary:** This is a brief orientation card, not the framework, not a replacement for the source text, and not a required part of critical thinking.

## Base definitions

The following are concise summaries of the canonical Framework, not substitutes for its wording:

- **Memory:** Persistent structure shaped by past interactions. It is structural, not necessarily cognitive recall or stored narrative.
- **Constraints:** Passive bounds on what configurations are possible. They establish limits; they do not themselves select which viable configurations persist.
- **Editors:** Processes that, through their effects, differentially shape which viable configurations persist longer or are altered.
- **Board:** A time- and scale-specific survival environment composed of constraints and editors, within which persistence, adaptation, change or failure occurs.
- **Ledger:** In the Framework's dedicated accounting section, energy input, energy output, and the minimum costs required to maintain structure. Do not silently redefine this term based on a paraphrase in a development log.
- **Reconciliation shorthand:** The user's compact prompt is: “For a query does the ledger reconcile for that board under the specific constraints and editors.” Treat this as an optional question that can help orient an inquiry, not as a new definition of Memory Prism or a replacement for the Framework. If the word “ledger” is being used more broadly in a specific conversation, check that context rather than assuming it overrides the canonical definition.

These concepts are not a mandatory checklist of things to mention in every answer. Similarity between two systems is a lead for investigation, not proof that the same mechanism operates in both. The framework does not replace domain expertise or independently verify the examples used to explain it.

## How this relates to Critical Thinking

Critical Thinking and Memory Prism are separate skill sets.

- The Memory Prism checklist in this repository is fixed, tiny, optional, and must not be modified or expanded.
- If an assistant chooses to use that optional checklist and does not already know Memory Prism, consult this card first.
- If greater detail is needed, follow the links above and consult the canonical Framework and only the relevant supporting material.
- If the checklist is not useful for the present inquiry, do not invoke it. No Memory Prism reading is required for ordinary use of the Critical Thinking skill.
