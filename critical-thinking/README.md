## Scope boundary

Critical thinking is developed on its own terms. The optional Memory Prism checklist is available as a separate reference; it is not a required step, a definition of critical thinking, or a framework to expand within this skill.

The published development logs preserve each assistant's record separately. They are evidence of the inquiry process in those particular runs, not proof that any assistant has mastered critical thinking.
