# Critical Thinking

**Status:** In development; not a finished AI skill.

Critical thinking and Memory Prism are separate skill sets.

Critical thinking is being developed around curiosity, reasoned mismatches, examination of assumptions and evidence, revision, and the ability to leave a question unresolved when it cannot yet be reconciled.

Memory Prism is not the governing framework for this work. A tiny, fixed, optional Memory Prism checklist is available as a read-only adjunct:

- [Memory Prism Checklist](MEMORY-PRISM-CHECKLIST.md)

The checklist must not be modified or expanded, and its use is never compulsory. Critical-thinking work proceeds normally when the checklist is not used. This optional reference does not combine the skill sets.
